AYURVEDA VEDA - STYLE & COLOR GUIDE
========================================
All website colors are managed via CSS Variables in 'src/globals.css'.

TO CHANGE THE VIBE:
1. Open 'src/globals.css'
2. Find the ':root' section (Lines 6-52).
3. Replace the values for the variables below.

----------------------------------------

PRO TIP:

- Second number: How intense the color is (%)
